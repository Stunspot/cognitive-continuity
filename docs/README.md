# Cognitive Continuity project site

This directory is the static GitHub Pages source for **Cognitive Continuity**.

- `index.html` contains the semantic landing page.
- `style.css` contains responsive, keyboard-visible, reduced-motion-aware presentation.
- `assets/cognitive-continuity-hero.png` is a generated 1600×900 PNG stored in the repository.
- `.nojekyll` asks GitHub Pages to serve the files directly.

The site uses no JavaScript, analytics, downloaded webfont, framework, or coded SVG artwork. It describes the canonical standalone `0.2.4` source release. Packaged distribution, installation, host discovery, invocation, persistent-store health, cloud replication, and physical-media survival remain separate evidence states.
